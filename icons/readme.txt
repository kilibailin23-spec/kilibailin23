  画的时候注意两点：
  1. 图形用纯黑（#000）描边或填充就行，**颜色不用管**。代码里是用
     mask-image 把它当「模板」用的，只取形状，颜色由 CSS 的 currentColor 决定，
     所以亮色/暗色主题下会自动跟着变。
  2. 画布按 24×24 来画，四周留 2px 左右的安全边距，别顶到边。
     代码里统一缩放到 1.25em，各图标笔画粗细要看起来一致。

  ---------------------------------------------------------------
  出问题了怎么查
  ---------------------------------------------------------------

  【某个位置出现一个实心方块】
  这是最常见的故障，意思是**那个文件名对不上**（拼错了、大小写不对、
  或者后缀不是 .svg）。mask 加载失败的时候不会显示空白，而是把整块
  背景色露出来，所以看着就是个方块。
  排查：打开浏览器控制台，看有没有 404，缺哪个名字一比就知道。
  或者对照上面那张表核一遍。

  【图标是空的 / 什么都没有】
  文件名对了，但 SVG 里面的图形跑到画布外了（比如 viewBox 写错、
  或者坐标超出 24×24）。用浏览器单独打开那个 .svg 看一眼就知道。

  【图标颜色不对】
  这个不影响使用 —— 文件里填什么颜色都会被忽略，形状画对就行。

  ---------------------------------------------------------------
  不想用图标文件夹了
  ---------------------------------------------------------------
  把 index.html 里 SITE 的 iconDir 改成 null，就退回用文字/表情符号。
  这个文件夹可以整个删掉。
