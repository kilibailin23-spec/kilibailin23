把你的下载文件（PDF、ZIP、PPT……）直接放进这个 files 文件夹。

然后在 index.html 里找到 FILES 这一段，照着格式加一条：

  const FILES = [
    {
      name: '我的简历.pdf',              // 显示的名字
      file: './files/我的简历.pdf',       // 相对路径，指向这个文件夹里的文件
      size: '320 KB',                    // 手动写，或者留空 ''
      desc: '一句话说明'                  // 可留空
    }
  ]

注意几点：

1. 路径一定要写 ./files/ 开头，不要写成 /files/（绝对路径，
   如果网站部署在子目录里会 404）。

2. 文件名里的空格最好换成下划线，中文没问题。

3. 单文件别超过 25MB —— Cloudflare Pages / GitHub Pages 都有
   单文件大小上限，超了传不上去。大文件建议传网盘，下载条目里
   的 file 字段直接写网盘链接也行（但那样就没有 download 属性了，
   会在新标签页打开）。

4. 这个说明文件本身可以删掉。
